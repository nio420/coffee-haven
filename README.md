# ☕ Coffee Haven

[![React](https://img.shields.io/badge/React-18-blue?logo=react&logoColor=white)](https://reactjs.org/)
[![TailwindCSS](https://img.shields.io/badge/TailwindCSS-3.3-blue?logo=tailwind-css&logoColor=white)](https://tailwindcss.com/)
[![Redux](https://img.shields.io/badge/Redux-Toolkit-purple?logo=redux&logoColor=white)](https://redux.js.org/)
[![Framer Motion](https://img.shields.io/badge/Framer%20Motion-1.26-pink?logo=framer&logoColor=white)](https://www.framer.com/motion/)

A modern, responsive, and animated coffee shop website built with **React**, **TailwindCSS**, **Redux**, and **Framer Motion**.

---

## 🌟 Features

- Responsive layout for desktop and mobile
- Smooth scroll navigation between sections
- Dark/Light theme toggle
- Favorites system using Redux
- Animated Hero, Menu, About, Testimonials, and Footer sections
- Interactive Menu cards with hover effects
- Glassmorphism UI elements
- Contact form with styled inputs
- Hamburger menu for mobile with toggle icons

## 💻 Installation

1. Clone the repository:

```bash
git clone https://github.com/nio420/coffee-haven.git

Navigate into the project directory:
cd coffee-haven

Install dependencies:
npm install

🚀 Running the Project

Start the development server:
npm run dev

Open your browser and go to:
http://localhost:5173


🛠 Technologies Used:

React.js - Frontend framework
TailwindCSS - Utility-first CSS for styling
Redux Toolkit - State management
Framer Motion - Animations
React Icons & Lucide - Icons
```
